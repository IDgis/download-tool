# Stage 3: Play 2.6 → 2.7 → 2.8 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> **Rewritten after Stage 2 execution (2026-08-05).** The original version of this plan assumed `controllers.WebJarAssets` still existed going into Play 2.7/2.8, and that `play.Play.application()`/`play.Configuration` only needed replacing at 2.8. Both assumptions were wrong, verified against the actual published jars — see the corrections below.

**Goal:** Advance Play from 2.6 to 2.8. The two things that actually force code changes in this range are: (1) `play.Play` and `play.Configuration` — the Java-facing wrapper classes, not just individual deprecated methods — are removed **entirely at Play 2.7.0**, one version earlier than originally planned; every constructor that takes `play.Configuration`, plus `layout.scala.html`'s `play.Play.application()` calls, must migrate to `com.typesafe.config.Config` in micro-commit 1. (2) The `response()` mutation API (`response().setHeader()`/`setContentType()`) is removed at Play 2.8, confirmed correct in the original plan — that stays in micro-commit 2.

**Not in this stage's scope:** the `WebJarAssets` → `WebJarsUtil` migration. It was originally planned for this stage but turned out to be forced at Play 2.6 itself (the `webjars-play_2.12` artifact dropped `controllers.WebJarAssets` starting at its very first `_2.12` release), so it was already completed during Stage 2. If you're looking at this plan and `WebJarAssets` references still exist in the codebase, something is out of sync — check Stage 2's plan/status first.

**Architecture:** Two micro-commits on one branch, same as originally planned, but the weight has shifted: micro-commit 1 (Play 2.7) is now the large change (every `play.Configuration` usage across the app, plus the `layout.scala.html` config-threading), and micro-commit 2 (Play 2.8) is comparatively small (just `response()` removal in two controllers).

**Tech Stack:** Gradle 8.8, Play 2.7.9 (intermediate) → 2.8.22, Scala 2.12, Java 8

**Verified facts this plan relies on** (checked via `javap` against the actual published jars, not assumed):
- `play/Play.class` and `play/Configuration.class` (top-level `play` package) exist in `play_2.12:2.6.25`, are both **absent** from `play_2.12:2.7.9` and `play_2.12:2.8.22`. Only `play.api.Play`/`play.api.Configuration` (Scala side) remain.
- `com.typesafe.config.Config` has **no default-value overloads** (`getString(path)` throws `ConfigException.Missing` if absent; there is no `getString(path, default)`). Use `hasPath(path)` to guard optional keys.
- `Controller.response()` (and `ctx()`, `session()`, `flash()`, `lang()`) exist in `play_2.12:2.7.9`, are **absent** from `play_2.12:2.8.22` (only `TODO(Http.Request)` remains).
- `org.webjars:webjars-play_2.12` continues under the `org.webjars` Maven group through at least `2.8.18` — it does **not** rename to `org.webjars.play` (that's the Java package name inside the jar, not the Maven groupId; confirmed no artifacts exist under the `org.webjars.play` group).
- `play-ahc-ws_2.12` and `play-guice_2.12` both track normal Play versioning through `2.7.9`/`2.8.22` — no further renames at this stage.

- [ ] **Step 2: Migrate `util/Cache.java`**

Only call site is `config.getString("cache.path")` with no default — `application.conf` sets `cache.path = ${ZIP_CACHEPATH}` as a required substitution, so this key is always present by the time the app boots (an unresolved required substitution fails application startup, not this call). Straight type swap:

```java
import java.nio.file.FileSystems;
import java.nio.file.Files;
import java.nio.file.Path;

import com.typesafe.config.Config;

import controllers.DownloadResult;

import play.Logger;
import play.Logger.ALogger;

public class Cache {

	private static final ALogger log = Logger.of(Cache.class);

	static public Path get(Config config) {
		String cachePath = config.getString("cache.path");

		log.debug("cache.path: " + cachePath);

		Path cache = FileSystems.getDefault().getPath(cachePath);

		if(!Files.exists(cache)) {
			throw new IllegalArgumentException("configured cache location doesn't exists");
		};

		return cache;
	}
}
```

Note: the old `if(cachePath == null)` guard is removed — `Config.getString` throws instead of returning `null`, so that branch was already unreachable in practice (the key is guaranteed present or the app fails to boot) and is now provably unreachable.

- [ ] **Step 3: Migrate `data/MetadataProvider.java`**

Change the import and constructor parameter from `play.Configuration` to `com.typesafe.config.Config`. Every call site except one is a required substitution in `application.conf` (`metadata.url`, `metadata.confidential-path`, `download.trusted.header`, `download.access` are all non-optional `${VAR}` substitutions) and is a direct swap. **The one exception:** `metadata.data-public-value` is declared as `data-public-value=${?DATA_PUBLIC_VALUE}` (optional substitution) in `application.conf`, and `MetadataProvider.get()` explicitly checks `if(dataPublicValue == null ...)`. `Config.getString` would throw instead of returning null here — this must be guarded with `hasPath`:

```java
import java.net.URL;
import java.net.MalformedURLException;
import java.util.Optional;
import java.util.concurrent.CompletableFuture;
import java.util.concurrent.CompletionStage;

import javax.inject.Inject;

import models.MetadataDocument;

import com.typesafe.config.Config;

import play.libs.ws.WSClient;

public class MetadataProvider {

	private final Config config;

	private final WSClient ws;

	@Inject
	public MetadataProvider(Config config, WSClient ws) {
		this.config = config;
		this.ws = ws;
	}

	public String getTrustedHeader() {
		return config.getString("download.trusted.header");
	}

	public String getTrustedValue() {
		String access = config.getString("download.access");
		if("intern".equals(access)) {
			return "1";
		} else {
			return "0";
		}
	}

	public CompletionStage<Optional<MetadataDocument>> get(String id) {
		try {
			URL url = new URL(config.getString("metadata.url") + id + ".xml");
			return ws.url(url.toExternalForm())
				.setFollowRedirects(true)
				.setHeader(getTrustedHeader(), getTrustedValue())
				.get()
				.thenApply(response -> {
					if(response.getStatus() == 200) {
						MetadataDocument metadataDocument = new MetadataDocument(url, response.asXml());

						String confidentialPath = config.getString("metadata.confidential-path");
						String dataPublicValue = config.hasPath("metadata.data-public-value")
							? config.getString("metadata.data-public-value")
							: null;
						if(dataPublicValue == null
							|| metadataDocument.getresourceConstraints(confidentialPath)
								.contains(dataPublicValue)
							|| "intern".equals(config.getString("download.access"))) {
							return Optional.of(metadataDocument);
						}
					}

					return Optional.<MetadataDocument>empty();
				});
		} catch(MalformedURLException e) {
			CompletableFuture<Optional<MetadataDocument>> failed = new CompletableFuture<>();
			failed.completeExceptionally(e);
			return failed;
		}
	}
}
```

- [ ] **Step 7: Migrate `controllers/ZooKeeper.java` — the complex one**

This file uses `Configuration`'s default-value overloads extensively (`getString(path, default)`, `getStringList(path, default)`, `getBoolean(path, default)`, `getInt(path, default)`) and `.getConfig(path)`/`.keys()` for nested iteration — none of which exist the same way on `com.typesafe.config.Config`. `Config` has no default-value overloads at all (only `hasPath(path)` + single-arg getters), and no `.keys()` (use `.root().keySet()` for direct child keys — `ConfigObject` implements `Map<String, ConfigValue>`).

Full replacement:

```java
package controllers;

import java.util.ArrayList;
import java.util.Collections;
import java.util.HashMap;
import java.util.List;
import java.util.Map;
import java.util.concurrent.CompletableFuture;

import javax.inject.Inject;
import javax.inject.Singleton;

import com.typesafe.config.Config;

import nl.idgis.sys.provisioning.domain.ProxyDomain;
import nl.idgis.sys.provisioning.domain.ProxyDomain.Alias;
import nl.idgis.sys.provisioning.domain.ProxyMapping;
import nl.idgis.sys.provisioning.domain.ProxyMappingType;
import nl.idgis.sys.provisioning.domain.ProxyPath;
import nl.idgis.sys.provisioning.registration.ServiceRegistration;
import nl.idgis.sys.provisioning.registration.ServiceRegistrationException;
import play.Logger;
import play.inject.ApplicationLifecycle;

/**
 * The class for the zookeeper entity
 *
 * @author Sandro
 *
 */
@Singleton
public class ZooKeeper {

	private ServiceRegistration serviceRegistration = null;

	@Inject
	public ZooKeeper (final Config configuration, final ApplicationLifecycle applicationLifecycle) {
		// ZooKeeper registration:

		final String zooKeeperHosts = getString(configuration, "zooKeeper.hosts", null);
		if (zooKeeperHosts != null) {
			try {
				registerService (zooKeeperHosts, configuration);
				Logger.info("Registering has been successful");
			} catch (ServiceRegistrationException e) {
				Logger.error ("ZooKeeper registration failed", e);
			}

			applicationLifecycle.addStopHook (() -> {
				try {
					serviceRegistration.close ();
				} catch (Exception e) {
					Logger.error ("Failed to terminate ZooKeeper registration", e);
				}
				return CompletableFuture.completedFuture (null);
			});
		} else {
			Logger.error("Registering has been unsuccessful");
		}

	}

	private static String getString(final Config config, final String path, final String defaultValue) {
		return config.hasPath(path) ? config.getString(path) : defaultValue;
	}

	private static boolean getBoolean(final Config config, final String path, final boolean defaultValue) {
		return config.hasPath(path) ? config.getBoolean(path) : defaultValue;
	}

	private static int getInt(final Config config, final String path, final int defaultValue) {
		return config.hasPath(path) ? config.getInt(path) : defaultValue;
	}

	private static List<String> getStringList(final Config config, final String path, final List<String> defaultValue) {
		return config.hasPath(path) ? config.getStringList(path) : defaultValue;
	}

	/**
	 * Performs the ZooKeeper registration for this Play application. Reads the configuration stored under
	 * the "service" key in application.conf and turns it into registrations for {@link ProxyDomain},
	 * {@link ProxyMapping} and {@link ProxyPath}.
	 *
	 * @param zooKeeperHosts	The ZooKeeper hosts to connect with.
	 * @param config			The application config
	 * @throws					ServiceRegistrationException
	 */
	private void registerService (final String zooKeeperHosts, final Config config) throws ServiceRegistrationException {
		Logger.info ("Registering with ZooKeeper cluster at " + zooKeeperHosts);

		// Start the service registration daemon:
		serviceRegistration = new ServiceRegistration (zooKeeperHosts, getString(config, "zooKeeper.namespace", null));

		// Add a proxy domain:
		final String domain = getString(config, "service.domain.name", "localhost");
		final List<Alias> aliases = new ArrayList<> ();
		final Map<String, List<String>> additionalConfig = new HashMap<> ();

		for (final String alias: getStringList(config, "service.domain.aliases", Collections.<String>emptyList ())) {
			aliases.add (new Alias (alias, false));
		}

		if (config.hasPath ("service.domain.additionalConfig")) {
			final Config additional = config.getConfig ("service.domain.additionalConfig");
			for (final String configName: additional.root ().keySet ()) {
				final List<String> configList = new ArrayList<> ();

				for (final String c: additional.getStringList (configName)) {
					if (!c.trim ().isEmpty ()) {
						configList.add (c);
					}
				}

				if (!configList.isEmpty ()) {
					additionalConfig.put (configName, configList);
				}
			}
		}

		serviceRegistration.registerProxyDomain (new ProxyDomain (
			domain,
			getBoolean(config, "service.domain.supportHttps", false),
			aliases,
			additionalConfig
		));

		// Generate a proxy mapping for this Play! application:
		final String path = getString(config, "application.context", "/");
		final int port = getInt(config, "http.port", 9000);
		final String destinationIP = getString(config, "service.mapping.destinationIP", ServiceRegistration.getPublicIp ());
		serviceRegistration.registerProxyMapping (new ProxyMapping (
			domain,
			path,
			"http://" + destinationIP + ":" + port + path,
			ProxyMappingType.HTTP
		));

		// The download path: force HTTPS and exclude from statistics.
		serviceRegistration.registerProxyPath (new ProxyPath (
			domain,
			mkPath (path, "/download"),
			true,
			true,
			null,
			null,
			null
		));

		// The metadata path: force HTTPS and exclude from statistics.
		serviceRegistration.registerProxyPath (new ProxyPath (
			domain,
			mkPath (path, "/metadata"),
			true,
			true,
			null,
			null,
			null
		));

		// The assets path: exclude from statistics.
		serviceRegistration.registerProxyPath (new ProxyPath (
			domain,
			mkPath (path, "/assets"),
			false,
			true,
			null,
			null,
			null
		));

		// Register secured paths:
		if (config.hasPath ("service.securedPaths")) {
			final Config securedPathsConfiguration = config.getConfig ("service.securedPaths");
			for (final String securedPath: securedPathsConfiguration.root ().keySet ()) {
				final String value = getString(securedPathsConfiguration, securedPath, null);
				if (value == null) {
					continue;
				}

				final List<String> ips = new ArrayList<> ();
				for (final String s: value.split (",")) {
					if (!s.trim ().isEmpty ()) {
						ips.add (s.trim ());
					}
				}

				if (ips.isEmpty ()) {
					continue;
				}

				serviceRegistration.registerProxyPath (new ProxyPath (
					domain,
					securedPath.startsWith ("/") ? securedPath : "/" + securedPath,
					false,
					false,
					null,
					ips,
					null
				));
			}
		}

	}

	/**
	 * Returns a path constructed from a base path and a subpath. Makes sure that the basePath and
	 * subPath are always separated by a single slash, regardless of whether the inputs starts or
	 * ends with a slash.
	 *
	 * @param basePath	The base path, optionally ending with a slash.
	 * @param subPath	The subpath to add, optionally starting with a slash.
	 * @return			The combined path where a single slash separates basePath and supPath.
	 */
	private static String mkPath (final String basePath, final String subPath) {
		final String base = basePath.endsWith ("/") ? basePath.substring (0, basePath.length () - 1) : basePath;
		final String sub = subPath.startsWith ("/") ? subPath : "/" + subPath;

		return base + sub;
	}
}
```

Key changes from the original: added four small `hasPath`-guarded helper methods to replace `Configuration`'s default-value overloads; `additional.keys()`/`securedPathsConfiguration.keys()` → `.root().keySet()`; guarded the two `getConfig(...)` calls with `hasPath` first, since `Config.getConfig()` throws if the path is absent (the old `Configuration.getConfig()` returned an empty `Configuration` instead) — without the guard, a deployment that doesn't set `service.domain.additionalConfig` or `service.securedPaths` (very plausible; these are optional ops-level knobs, matching that `zooKeeperHosts` itself is usually absent in this codebase's dev/test environments) would throw instead of skipping the block.
