# Stage 2: Play 2.4.6 → 2.5 → 2.6 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> **✅ Executed and committed 2026-08-05 (commits `6056c20`, `0cf4254`), verified end-to-end in Docker (download + error page both confirmed working).** The text below is the plan **as originally written**, kept as-is for history — it does not reflect what was actually done. Real execution deviated substantially; the list below is what actually happened, most relevant for Stage 3+ to build on:
>
> - **Task 2 (2.5) stayed on Scala 2.11, not 2.12.** No `_2.12` artifacts exist for Play 2.5.x on Maven Central at all (confirmed via build failure + Maven Central listing) — the Scala switch actually happens at Task 4 (2.6), where `_2.12` artifacts genuinely start existing.
> - **`playTest` isn't a valid Gradle configuration** in this project's plugin setup — `h2` stayed on `play`, not `playTest`.
> - **`gson` must stay in the Task 2 dependency block** — the plan's snippet omits it, but `DownloadForm.java` uses it directly.
> - **`MetadataProvider.java`'s `.setFollowRedirects`/`.setHeader` were NOT renamed to `.withFollowRedirects`/`.withHeader`** at either 2.5 or 2.6 (verified via decompiled `WSRequest.class` at 2.6.25) — the plan's Task 4 Step 2 snippet showing `.withFollowRedirects`/`.withHeader` is wrong; the old names stayed.
> - **`ErrorHandler.java` needed `Provider<WebJarAssets>` at Task 2 (2.5)**, not direct injection — Play 2.5 disables Guice circular proxies by default, and `ErrorHandler`↔`WebJarAssets` is a genuine constructor cycle. This became moot again at Task 4 once `WebJarAssets` was replaced by `WebJarsUtil` (see next point) — `WebJarsUtil`'s constructor doesn't depend on `HttpErrorHandler`, so `ErrorHandler` injects it directly with no `Provider`, as Task 4's snippet below already (correctly, if accidentally) shows.
> - **The `WebJarAssets` → `WebJarsUtil` migration — originally planned for Stage 3 — was actually forced here, at Task 4 (Play 2.6).** `webjars-play_2.12` dropped `controllers.WebJarAssets` entirely starting at its very first `_2.12` release (2.6.0), not at 2.7/2.8. This pulled a big chunk of what used to be Stage 3's work into this stage: `conf/routes`, `DownloadForm/Raster/Result.java`, `ErrorHandler.java`, and all 7 templates all needed the `WebJarAssets`→`WebJarsUtil` rename here, not later. Stage 3's plan has since been rewritten to reflect this (its `WebJarAssets` section is gone).
> - **`play-java-ws_2.12` doesn't exist** — renamed to `play-ahc-ws_2.12` starting Scala 2.12/Play 2.6. Task 4's dependency block (`play-java-ws_2.12:2.6.25`) is wrong; use `play-ahc-ws_2.12`.
> - **Play 2.6 extracted Guice DI support into a separate `play-guice_2.12` artifact.** Not in the plan's dependency block at all — without it, `web/app/DownloadModule.java` (`com.google.inject.AbstractModule`, not mentioned anywhere in this plan's file lists) fails to compile.
> - **`web/app/controllers/ZooKeeper.java` — also not mentioned anywhere in this plan — had the actual `F.Promise` usage** this stage needed to remove, in an `ApplicationLifecycle.addStopHook()` lambda. Task 3's assessment of the vendored `provisioning-registration` library was correct (it's clean, no Play dependency) but incomplete — the Promise usage was in this app's own code wrapping that library, not the library itself.
> - **Runtime-only bug `./gradlew build`/`SmokeTest` never caught:** `DownloadForm.post()`'s `bindFromRequest()` (no-arg) threw `RuntimeException: There is no HTTP Context available from here` on an actual `POST /download` in Docker, because the surrounding lambda became a `CompletionStage.thenApply` continuation that can run on a different thread than the request thread. Fixed by capturing `request()` synchronously before the async lambda and using the explicit-request `bindFromRequest(request)` overload. `SmokeTest` only exercises `GET /help` — this is why later stages' plans now say not to trust `./gradlew build` alone.
> - `error.scala.html`'s `play.api.UsefulException` (Step 6's fallback) was never needed — it compiled fine at 2.6.
>
> Full details on all of the above: see the `project-migration` memory file.

**Goal:** Advance Play from 2.4.6 to 2.6, removing all `F.Promise` usage, migrating `Form.form()` to `FormFactory`, and updating the `ErrorHandler` and JavaScript router API.

**Architecture:** Two micro-commits on one branch. Play 2.5 is an intermediate waypoint where `F.Promise` is deprecated but still compiles — get a green build there before removing it in 2.6. The largest code changes are in `DownloadForm.java` and `MetadataProvider.java`, which return async results. `Metadata.java` is simpler (passthrough). `ErrorHandler.java` needs a constructor signature update for Play 2.6's `DefaultHttpErrorHandler`.

**Tech Stack:** Gradle 8.8, Play 2.5.18 (intermediate) → 2.6.25, Scala 2.12 (switched at 2.5), Java 8

- [ ] **Step 2: Migrate `MetadataProvider.java`**

`web/app/data/MetadataProvider.java` — full replacement:

```java
package data;

import java.net.URL;
import java.net.MalformedURLException;
import java.util.Optional;
import java.util.concurrent.CompletableFuture;
import java.util.concurrent.CompletionStage;

import javax.inject.Inject;

import models.MetadataDocument;

import play.Configuration;
import play.libs.ws.WSClient;

public class MetadataProvider {

    private final Configuration config;

    private final WSClient ws;

    @Inject
    public MetadataProvider(Configuration config, WSClient ws) {
        this.config = config;
        this.ws = ws;
    }

    public String getTrustedHeader() {
        return config.getString("download.trusted.header");
    }

    public String getTrustedValue() {
        String access = config.getString("download.access");
        if ("intern".equals(access)) {
            return "1";
        } else {
            return "0";
        }
    }

    public CompletionStage<Optional<MetadataDocument>> get(String id) {
        try {
            URL url = new URL(config.getString("metadata.url") + id + ".xml");
            return ws.url(url.toExternalForm())
                .withFollowRedirects(true)
                .withHeader(getTrustedHeader(), getTrustedValue())
                .get()
                .thenApply(response -> {
                    if (response.getStatus() == 200) {
                        MetadataDocument metadataDocument = new MetadataDocument(url, response.asXml());

                        String confidentialPath = config.getString("metadata.confidential-path");
                        String dataPublicValue = config.getString("metadata.data-public-value");
                        if (dataPublicValue == null
                            || metadataDocument.getresourceConstraints(confidentialPath)
                                .contains(dataPublicValue)
                            || "intern".equals(config.getString("download.access"))) {
                            return Optional.of(metadataDocument);
                        }
                    }

                    return Optional.<MetadataDocument>empty();
                });
        } catch (MalformedURLException e) {
            CompletableFuture<Optional<MetadataDocument>> failed = new CompletableFuture<>();
            failed.completeExceptionally(e);
            return failed;
        }
    }
}
```

Key changes: `Promise<Optional<...>>` → `CompletionStage<Optional<...>>`, `.setFollowRedirects` → `.withFollowRedirects`, `.setHeader` → `.withHeader`, `.map(` → `.thenApply(`, `Promise.throwing(e)` → failed `CompletableFuture`.

- [ ] **Step 3: Migrate `Metadata.java`**

`web/app/controllers/Metadata.java` — full replacement:

```java
package controllers;

import java.io.ByteArrayOutputStream;
import java.util.concurrent.CompletionStage;

import javax.inject.Inject;

import javax.xml.transform.Transformer;
import javax.xml.transform.TransformerFactory;
import javax.xml.transform.dom.DOMSource;
import javax.xml.transform.stream.StreamResult;

import org.w3c.dom.Node;
import org.w3c.dom.NodeList;
import org.w3c.dom.ProcessingInstruction;
import org.w3c.dom.Document;

import play.mvc.Result;
import play.mvc.Controller;

import data.MetadataProvider;

public class Metadata extends Controller {

    private final MetadataProvider metadataProvider;

    @Inject
    public Metadata(MetadataProvider metadataProvider) {
        this.metadataProvider = metadataProvider;
    }

    public CompletionStage<Result> get(String id) {
        return metadataProvider.get(id).thenApply(metadataDocument -> {
            if (metadataDocument.isPresent()) {
                Document document = metadataDocument.get().getDocument();

                NodeList children = document.getChildNodes();
                for (int i = 0; i < children.getLength(); i++) {
                    Node n = children.item(i);
                    if (n.getNodeType() == Node.PROCESSING_INSTRUCTION_NODE) {
                        ProcessingInstruction pi = (ProcessingInstruction) n;
                        if ("xml-stylesheet".equals(pi.getTarget())) {
                            document.removeChild(pi);
                        }
                    }
                }

                document.insertBefore(
                    document.createProcessingInstruction(
                        "xml-stylesheet",
                        "type=\"text/xsl\" href=\"metadata.xsl\""),
                    document.getFirstChild());

                ByteArrayOutputStream output = new ByteArrayOutputStream();
                try {
                    TransformerFactory tf = TransformerFactory.newInstance();
                    Transformer t = tf.newTransformer();
                    t.transform(new DOMSource(document), new StreamResult(output));
                    output.close();
                } catch (Exception e) {
                    throw new RuntimeException(e);
                }

                return ok(output.toByteArray()).as("application/xml");
            } else {
                return notFound();
            }
        });
    }
}
```

- [ ] **Step 5: Migrate `ErrorHandler.java`**

`web/app/ErrorHandler.java` — full replacement:

```java
import javax.inject.Inject;
import javax.inject.Provider;
import java.util.concurrent.CompletableFuture;
import java.util.concurrent.CompletionStage;

import com.typesafe.config.Config;

import controllers.WebJarAssets;
import play.Environment;
import play.api.OptionalSourceMapper;
import play.api.UsefulException;
import play.api.routing.Router;
import play.http.DefaultHttpErrorHandler;
import play.mvc.Controller;
import play.mvc.Http.RequestHeader;
import play.mvc.Result;

import views.html.error;

public class ErrorHandler extends DefaultHttpErrorHandler {

    private final WebJarAssets webJarAssets;

    @Inject
    public ErrorHandler(WebJarAssets webJarAssets, Config config, Environment environment,
            OptionalSourceMapper sourceMapper, Provider<Router> routes) {
        super(config, environment, sourceMapper, routes);
        this.webJarAssets = webJarAssets;
    }

    @Override
    protected CompletionStage<Result> onProdServerError(RequestHeader request, UsefulException exception) {
        return CompletableFuture.completedFuture(
            Controller.internalServerError(error.render(webJarAssets, exception)));
    }
}
```

Key changes: `Configuration` → `Config` (constructor + import), `Promise<Result>` → `CompletionStage<Result>`, `Promise.pure(...)` → `CompletableFuture.completedFuture(...)`.
